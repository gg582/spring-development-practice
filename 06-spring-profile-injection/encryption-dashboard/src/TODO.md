## 리폼해야 할 사항

- Spring Boot 기준으로 소스를 잘못 잡음
- 아직 직접 App.java에서 Spring Boot 호출은 안 함
- *파일 재명명으로 끝날 일인지, 소스 지워야 하는지?*
  - Spring 4.x 기준으로 작업해야 한다.
- BouncyCastle 사용이 꽤 더럽다.
  - 리팩토링 가능한지 보고 정리해 보자.
- **CRUD가 잘 되어있지 않다.**
  - 구현을 끝낼 수 있다면 이번 주 내로 토이 프로젝트의 뼈대 잡자
    - **MVP 구현은 적어도 다음 주 초까진 하자. 그럼 고용 기간의 30%가 지나가기 전에는 끝나는 것이다.**
