## 완료한 것

- 암호화 매니저 최소 구현
  - exec.sh를 통해 AES256과 ChaCha20 간 코드 수정 없는 알고리즘 전환 성공
- 사용자 요청으로부터 파일, PW 등 받아서 리턴 성공

## 완료하지 못한 것

- **복호화 매니저 구현 및 통합**
  - 암호화 매니저와 동일한 구조를 따라야 함
- 암호화, 복호화 결과를 디버깅용 JSON이 아닌 Stream Body 형태로 전달
- 과거 암호화, 복호화 내역 보여주고 필터링하는 로직
- HTML+CSS로 간단한 UI 작성
- 대용량 파일에 대한 네트워크 스트링

## 유의 사항
- Java의 NIO는 고도로 추상화되어있음
  - C언어의 IO 라이브러리들과 달리 함수가 아닌 객체 기반으로 볼 것
- 파일 내역에 대한 기록과 필터링
  - MyBatis를 이용해서 기록할 것
  - 가능하면 영속성을 위해 PostgreSQL 9.6을 추가
- 스프링부트의 App.java 구조가 아님
  - Controller를 중심으로 CRUD 작업이 설계됨
- Spring 4.x 버전의 호환성 이슈
  - 블로그들은 대부분 Spring 5.x - 6.x 기준임
  - 블로그의 예제를 따라하면 Spring 4.x라는 레거시 제약 사항을 어김
- 파일 서버를 어떻게 구현할 것인지?
  - PostgreSQL 안에 파일 바디까지 밀어넣을 것인지?
  - 파일은 /opt 등에 별도의 파일 저장소를 두고 PostgreSQL 정보를 통해 파일의 경로만 찾을 것인지?
